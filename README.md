# Lead-to-Cash Automation — Antigravity Project

A project workspace derived from the Oyebode Antigravity Product System template.

## Included reusable systems

- `oyebode-builder` — problem-to-production SaaS operating system.
- `oyebode-product-brand-studio` — product-specific brand and design-system workflow.
- `skill-creator` — preserved infrastructure for future skill work; do not modify during normal product development.

## Project-specific additions

- `PROJECT-README.md` — working problem/product context.
- `PROJECT-PROMPTS.md` — exact prompt sequence for this project.
- `docs/` — focused product decision and evidence artifacts.
- `execution/` — deterministic project scripts only when needed.

## Important

This project is not a clone of the Upwork client's implementation. The Upwork brief is only the starting market/problem signal supplied by the user.
