# Product Design System Template

## 1. Design principles

Write 4–7 principles that govern decisions, such as:
- clarity before decoration
- dense where action requires scanning
- calm hierarchy for operational work
- feedback is immediate and explicit
- primary actions are visually obvious

## 3. Typography

Define family, scale, weight, line-height, tracking, and usage.

## 4. Layout

Define container widths, grids, spacing scale, section rhythm, and breakpoint behavior.

## 5. Shape/depth

Define radii, borders, shadows, dividers, and focus styles.

## 6. Components

For each used component define:
- purpose
- anatomy
- variants
- sizes
- states
- content rules
- accessibility behavior
- responsive behavior

## 7. Motion

Define where motion helps:
- navigation
- feedback
- state transition
- progressive disclosure

Avoid motion that delays comprehension or creates decorative noise.

## 8. State system

Every important component should account for:
- default
- hover
- focus
- pressed
- disabled
- loading
- success
- error
- empty
- permission-restricted

## 9. Responsive system

Define behavior by layout constraints, not only device names.
