# Anti-Generic-AI UI Review

This is a review framework, not a banned-style list.

## Warning signals

- decorative gradients with no semantic reason
- identical purple/blue AI palettes across unrelated products
- excessive glass surfaces
- overly rounded cards everywhere
- giant marketing typography on workflow-heavy screens
- repeated three-card layouts with no content reason
- floating decorative blobs
- “AI-powered” attached to every feature
- fabricated metrics or testimonials
- animation everywhere
- excessive empty space where users need dense information
- generic dashboard illustrations replacing actual product states
- identical landing-page patterns copied from unrelated SaaS templates

## Review questions

1. What does each visual element help the user understand or do?
2. Does the visual hierarchy match task priority?
3. Does density match the job?
4. Does the product feel appropriate for its category?
5. Can a user tell what is happening without decoration?
6. Are important states explicit?
7. Does the interface still feel coherent with motion removed?
8. Could a different company plausibly have received the same template? If yes, what should become more
product-specific?

## Correction strategy

Prefer:
- stronger hierarchy
- product-specific terminology
- meaningful data density
- distinct information architecture
- purposeful color semantics
- real states and content
- clear feedback
- intentional image treatment
- subtle, useful motion

The objective is not to make the UI anti-modern. It is to make every modern element earn its place.
