# Oyebode Builder

**Skill ID:** `oyebode-builder`

`SKILL.md` is the Antigravity entrypoint. `BUILDER.md` is the full operating manual. The `references/`, `evals/`, and `scripts/` directories support the builder.

The builder is for real solution work: problem discovery, validation, product strategy, UX, engineering, AI/automation, launch, measurement, and iteration.

When the product needs an independent brand/design system, pair this skill with `oyebode-product-brand-studio`.
